## Overview

Industrial floors today rely on physical walkthroughs or passive monitor-watching to detect incidents, operational patterns, and bottlenecks. This approach struggles to cover multiple zones simultaneously and makes post-shift reconstruction tedious and error-prone.

**AI Co-Pilot for the Production Floor** ingests multiple RTSP video streams and combines real-time object detection (YOLOv8), multi-object tracking (DeepSORT), and visual-language reasoning (Gemini Vision) to automatically generate a visual logbook of what happened on the floor — enabling near real-time supervision and post-shift analysis with measurable ROI.

## The Three Pillars

| Pillar | What it does | Tech |
|---|---|---|
| **Ver / See** | Ingests every camera and identifies people, machinery, and forklifts across zones. | YOLOv8 + DeepSORT |
| **Guiar / Guide** | Sends near-real-time alerts on safety events, idle assets, and bottlenecks. | Gemini Vision + Telegram/JSON |
| **Mejorar / Improve** | Produces an automated visual logbook and KPIs for continuous improvement. | Custom analytics |

## Research Question

> Can a multi-camera, AI-based video analytics system generate an automated visual logbook that identifies operational patterns, bottlenecks, and critical events — reducing the need for direct human supervision of monitors?

## Project Objectives

1. Validate the feasibility of an AI multi-camera video analytics system that produces an automated visual logbook of operational patterns, bottlenecks, and critical events.
2. Build a Digital Twin of the production floor using **YOLOv8 + DeepSORT + Gemini Vision** to detect events such as accidents, machine stops, occupancy thresholds, and forklift activity.

## Getting Started

This project uses [uv](https://docs.astral.sh/uv/) to manage Python and dependencies.

\`\`\`bash

curl -LsSf https://astral.sh/uv/install.sh | sh

uv sync --all-groups
