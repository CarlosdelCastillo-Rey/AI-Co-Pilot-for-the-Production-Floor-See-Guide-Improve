02

Frozen Embedding Extraction

Extracted temporal embeddings from two pre-trained vision models. Each clip → 16 frames → top-down YOLO crop → transformer backbone (frozen weights) → 1024-dim embedding per clip. No fine-tuning of backbone ensures generalization.

V-JEPA 2

facebook/vjepa2-vitl-fpc64-256

  • • Masked Video Patch Prediction
  • • Temporal consistency learning
  • • 1024-dim embedding
  • • Frozen for HAR task

DINOv2

facebook/dinov2-large (ViT-L/14)

  • • Self-supervised learning
  • • Dense spatial features
  • • 1024-dim embedding
  • • Superior for action recognition

EMBEDDING EXTRACTION FORMULA

e_clip = TemporalPool(Backbone([crop_1, crop_2, ..., crop_16]))
where crop_i ∈ ℝ^(3×224×224) from YOLO
output: e_clip ∈ ℝ^1024

03

Multi-Improvement Training Pipeline

Trained shallow MLP head (1024→512→256→12) on frozen embeddings with four complementary improvements to handle extreme class imbalance.

✓ Focal Loss (γ=2.0)

Down-weights easy examples, focuses on hard/minority samples

L = -α_t · (1-p_t)^γ · log(p_t)

✓ Weighted Random Sampler

Rebalance mini-batches by inverse class frequency

w_c = 1/√(n_c) for each class c

✓ Mixup Augmentation (α=0.2)

Virtual training samples: 2,924 → 8,766 clips

x̃ = λ·x_i + (1-λ)·x_j, λ~Beta(α,α)

✓ CosineAnnealingLR

Smooth learning rate decay over 100 epochs

η_t = η_min + (η_0-η_min)·(1+cos(πt/T))/2

trainer = HarTrainer(
    head_arch="mlp",
    epochs=100,
    batch_size=64,
    use_focal_loss=True,
    use_mixup=True,
    use_weighted_sampler=True
)

Real-Time Inference in Backend

Backend loads checkpoint at startup, runs sliding-window inference on mock/RTSP streams. Per-frame YOLO detection + ByteTrack per-person + temporal HAR inference.

LIVE INFERENCE PIPELINE

1. Read frame from MP4 mock or RTSP stream
2. YOLO person detection → bounding boxes
3. ByteTrack: assign persistent track IDs
4. For each track: extract top-down crop (224×224)
5. Buffer 16 frames → DINOv2 backbone → embedding
6. MLP head → 12-class softmax probabilities
7. Log to SQLite (har_activity_logs) + promote deviations
8. Alert rule classifier → email/Telegram dispatch

Mathematical Foundation

Scientific principles underlying the HAR pipeline

Embedding Extraction

For each clip C with T frames and person track:

1. Extract top-down YOLO crop:
crop_i ∈ ℝ^(3×224×224)

2. Freeze backbone (no gradients):
f_i = Backbone(crop_i) ∈ ℝ^1024

3. Temporal aggregation (attention):
w_i = softmax(q^T · k_i / √d)
e_clip = Σ w_i · v_i ∈ ℝ^1024

Result: Per-clip embedding ready for classification

Focal Loss for Imbalance

Handles extreme class imbalance (16.4× ratio):

L_focal = -α_t · (1-p_t)^γ · log(p_t)

where:

  • • p_t = model's confidence in true class
  • • (1-p_t)^γ = modulation factor, γ=2
  • • α_t = class weight (inverse frequency)

Easy examples (high p_t) → γ ≈ 0 → loss ≈ 0
Hard examples (low p_t) → γ ≈ 2 → loss focus

Weighted Sampling

Each class weighted by √(inverse frequency):

w_c = 1 / √(n_c)

Example weights:

  • Turn sheets (512 clips): w=0.044
  • Picking left (31 clips): w=0.179

Result: Balanced mini-batches despite dataset skew. Each sample has equal expected contribution.

Mixup Augmentation

Virtual training samples via convex combination:

λ ~ Beta(α, α), α=0.2
x̃ = λ·x_i + (1-λ)·x_j
ỹ = λ·y_i + (1-λ)·y_j

Effect:

  • • 2,924 originals × 3 aug = 8,766 training
  • • Smoother decision boundaries
  • • Reduced overfitting to rare classes

Inference Softmax & Confidence

Given embedding e_clip, MLP outputs logits z:

z = W_out · h + b_out, where h ∈ ℝ^256
p(y=c | e_clip) = softmax(z)_c = exp(z_c) / Σ_k exp(z_k)
prediction = argmax(p), confidence = max(p)

Thresholding: Only promote to timeline if confidence > 0.25 (tunable)

Result: Per-action probability distribution enables alert weighting and uncertainty quantification.

Common Questions

Q: Why DINOv2 over V-JEPA?

DINOv2's self-supervised learning better captures spatial structure of industrial tasks. V-JEPA excels at temporal prediction but less discriminative for static action poses (e.g., "Consult sheets" vs. "Turn sheets").

Q: What about class imbalance?

Focal Loss + WeightedSampler + Mixup reduce but don't eliminate bias. Rare "Picking left" remains hard (F1=0.20). Future: collect more samples or use transfer learning from similar domains.

Q: Why frozen backbones?

Pre-trained vision models are expensive to fine-tune. Frozen ensures training is fast (45 min vs. hours), memory-efficient, and generalizes to new factories without retraining.

Q: Can we improve 41.5% accuracy?

Yes: collect more minority samples, use multi-view ensemble (top-down + side + front), or try ViT-G/14 backbone. HITL feedback loop (Step 6) will enable online learning.

Q: How does HITL improve models?

Supervisors correct mislabeled tracks in /har-hitl. These verdicts are saved. When we add APScheduler, verified samples automatically retrain models nightly without manual intervention.

Q: What's the inference cost?

~70-95ms per frame on GPU (YOLO 8-12ms + DINOv2 40-60ms + MLP <2ms). At 30 fps, one camera = ~300ms latency. Perfect for 2+ second window alerts.
